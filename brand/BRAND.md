# Olmera Brand Guide (one page)

**Idea:** an open ring (a circle of care that stays open to the patient) with one coral dot at the gap. The dot reads as a person, a pulse, or a notification.
**Personality:** calm, human, precise. Premium but never cold.

## Logo files (`brand/assets/`)
| File | Use |
|---|---|
| `app-icon.svg` | iOS icon master (export 1024x1024 PNG, no transparency, no rounded corners; iOS rounds it) |
| `android-adaptive-foreground.svg` | Android adaptive icon foreground; set the background layer to `#0E4F4A` |
| `favicon.svg` | Website favicon (`<link rel="icon" type="image/svg+xml" href="/favicon.svg">`); also export 32, 180 and 512 px PNGs |
| `logo-mark-dark-on-light.svg` | Mark on light backgrounds |
| `logo-mark-light-on-dark.svg` | Mark on dark backgrounds |
| `wordmark.svg` | Mark plus "olmera" lockup (needs Fraunces loaded) |

Clear space around the logo: twice the coral dot's diameter. Minimum mark size: 16 px.

## Type
Fraunces 500/600 for headlines. Instrument Sans 400/500/600 for everything else.

## Do / Don't
- Do use generous white space and rounded 12 to 18 px corners.
- Do use coral once per screen, for the main action or a key alert.
- Don't stretch, rotate, outline, or recolour the mark.
- Don't use generic medical imagery.

## Name status
Olmera is a shortlist pick, not cleared. Before launch: search trademark classes 9, 42 and 44, both app stores, domains, and social handles. Alternatives: Kenvara, Valdera. Do not use "MediCare".
