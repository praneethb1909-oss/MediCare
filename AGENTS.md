# Brand rule (always apply)

This project's brand is **Olmera** (working name; if the owner renames it, change only `--brand-name` in `brand/tokens.css` and the wordmark text). Tagline: "Care, quietly connected."

Before creating or editing any UI, logo, icon, splash screen, email, or marketing page:
1. Read `brand/BRAND.md`.
2. Import `brand/tokens.css`. Use only its CSS variables. Never hard-code hex colours or fonts.
3. Use only the SVGs in `brand/assets/`. Never redraw or recolour the logo.

Hard rules:
- Colours: Deep Fern primary, Parchment background, Ink text. Coral is an accent: at most one coral element per screen, never for body text.
- Fonts: Fraunces for headlines and the wordmark; Instrument Sans for all UI and body text.
- Do not use red crosses, hearts, stethoscopes, or stock medical clip art. Do not add gradients, glows, or drop shadows to the logo.
- Keep screens calm, spacious, and minimal. Large touch targets (44px+). Text contrast must meet WCAG AA.
